STEP 1: PUSH TO GITHUB (Manual)
────────────────────────────────────

If the automated push failed, do this manually:

    cd greenfuel-ml-frontend
    git add -A
    git commit -m "Add complete GreenFuel-ML full stack app"
    git push -u origin main --force

(Use your GitHub token when prompted for password)


STEP 2: ENABLE GITHUB PAGES (Frontend)
────────────────────────────────────────

1. Go to: https://github.com/Yuvibarot/GreenFuel-ML/settings/pages
2. Select "Deploy from a branch"
3. Choose: main branch, /root directory
4. Click Save
5. Wait 1-2 minutes
6. Your app will be live at: https://yuvibarot.github.io/GreenFuel-ML/


STEP 3: AWS DEPLOYMENT (Backend - RECOMMENDED)
──────────────────────────────────────────────

A. Install AWS tools:
    pip install awscli aws-sam-cli

B. Configure AWS:
    aws configure
    (Enter your AWS credentials)

C. Build:
    cd greenfuel-ml-frontend
    sam build

D. Deploy:
    sam deploy --guided

    Answers:
    - Stack name: greenfuel-ml-prod
    - Region: us-east-1
    - Confirm changes: y
    - IAM role creation: y

E. Get API endpoint from deployment output (save this URL!)

F. Update index.html:
    Find line: const API_BASE_URL = 'http://localhost:5000';
    Replace: const API_BASE_URL = 'https://YOUR-API-URL/prod';
    Find: const USE_MOCK_PREDICTIONS = true;
    Replace: const USE_MOCK_PREDICTIONS = false;

G. Push changes:
    git add index.html
    git commit -m "Connect to AWS backend"
    git push origin main


STEP 4: LOCAL TESTING (Optional)
──────────────────────────────────

    # Install dependencies
    pip install -r requirements.txt

    # Run backend
    cd greenfuel-ml-frontend
    python app.py

    # In another terminal:
    python -m http.server 8000

    # Open in browser:
    http://localhost:8000

═══════════════════════════════════════════════════════════════════════════════
                        📞 TROUBLESHOOTING QUICK FIX
═══════════════════════════════════════════════════════════════════════════════

Issue: Application not loading
  → Check browser console (F12)
  → Ensure files are in correct directory
  → Try clearing browser cache

Issue: Predictions not working
  → Check if backend is running
  → Verify API URL in index.html
  → Use mock predictions (browser-only)

Issue: CORS errors
  → Ensure Flask-CORS is installed
  → Check API endpoint is correct
  → Verify CORS headers in backend

Issue: Port 5000 already in use
  → Kill existing process: lsof -i :5000 | kill -9 <PID>
  → Or use different port: python app.py --port 5001

Issue: AWS deployment fails
  → Check AWS credentials: aws configure
  → Ensure IAM permissions
  → Try: sam deploy --guided (again)
